# Changelog

All notable changes to SQListo will be documented in this file.

## [0.2.0] - 2026-11-26 

### Added

- Automated Linux installation script.
- Automated language model download.
- Automated demonstration database download.
- SHA-256 integrity verification.
- Local llama.cpp installation.
- Scientific citation metadata.
- MIT software license.
- Third-party licensing documentation.
- Contribution guidelines.

### Changed

- Improved installation portability.
- Improved inference engine path resolution.
- Updated scientific and technical documentation.

## [0.1.0] - 2025-11-10

### Added

- Initial scientific preview of SQListo.
- Compressed molecular dynamics trajectory storage.
- TeraChem and VENUS trajectory processing.
- Fragmentation and reaction analysis.
- Molecular feature extraction.
- Theoretical mass spectrum construction.
- Global kinetic analysis.
- Local Qwen-based artificial intelligence assistant.
- SQLite database migration utilities.
- Regression tests and GitHub Actions workflow.
- Demonstration dataset containing 638 molecular dynamics trajectories.
